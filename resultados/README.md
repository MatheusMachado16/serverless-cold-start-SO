# resultados

CSVs brutos de cada rodada em `brutos/`. Nunca sobrescrever: um arquivo novo por rodada, por exemplo `rodada1_2026-10-10.csv`.

Colunas previstas: experimento, configuração, rodada, índice, tipo (frio ou quente), carimbo de tempo, latência fim a fim, tempo de criação do contêiner, tempo de execução, memória, descartada (sim ou não).
